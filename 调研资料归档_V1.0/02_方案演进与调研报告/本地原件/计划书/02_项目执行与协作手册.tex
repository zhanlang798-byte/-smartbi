\chapter*{Executive Summary / 执行摘要}
\addcontentsline{toc}{chapter}{Executive Summary / 执行摘要}

\begin{decisionbox}[执行总则]
团队按“R0 案例治理 -- R1 事实核验 -- G1 方向复审 -- R2 数据可得性 -- G2 样本冻结 -- R3 方法设计 -- G3 可证伪性审查 -- E1 正式执行 -- E2 看板实现 -- E3 提交验收”推进。任何人不得用后续工作替代前置门槛，也不得因为截止日期临近而删除美元基准、反例或不确定性。
\end{decisionbox}

\begin{itemize}
  \item \textbf{3 人与 4 人均可运行。}A 负责项目与 Smartbi 架构，B 统筹亚洲、非洲和拉丁美洲三个数据包，C 负责风险评分、事件研究与组合模型，D 负责企业年报、AIChat、报告、合规、视频与最终 QA；只有 3 人时 A 兼任 D。B 和 C 不合并，避免同一人同时生产并验证数据与模型。
  \item \textbf{七条工作流不是七人团队。}项目、亚洲、非洲、拉丁美洲、企业披露、风险模型、AI 与交付七条工作流由实际 3--4 名成员兼任，工作流负责人不等于新增编制。
  \item \textbf{交付物通过接口而非口头传递。}团队统一维护九张逻辑表、数据字典、来源台账、变更记录和门槛记录；所有模拟记录强制标记\Field{is_simulated=1}。
  \item \textbf{门槛有否决权。}G1 未通过不得进入数据建设；G2 未通过不得建模；G3 未通过不得给配置建议。门槛失败不是“拖延”，而是控制错误结论进入作品。
  \item \textbf{本阶段先评阅计划。}两册计划书经用户评阅并冻结后，团队才进入 R0。当前手册的日期是目标排程，不表示相应任务已经完成。
\end{itemize}

\section{项目负责人不是“万能审批人”}

\section{权威文件层级}
\begin{enumerate}

\section{目录与版本约定}
后续执行期建议使用以下逻辑目录；实际建立目录须在 G1 通过后进行：

\begin{verbatim}
project/
  00_governance/     # 冻结口径、会议记录、变更单
  01_sources/        # 来源目录与许可，不直接改原始文件
  02_raw/            # 只读原始快照

\section{状态词只允许五种}
任务状态统一为“未开始、进行中、待复核、通过、阻塞”。“差不多”“应该完成”“待优化”不能作为门槛状态。数据状态统一为“已确认、待复核、冲突、模拟、不适用”。

\section{会议节奏}
\begin{itemize}
  \item 每日 15 分钟站会：昨天完成、今天计划、阻塞、需要谁处理；
  \item 每晚发布一次状态快照：任务、输出路径、版本、验证人、遗留问题；
  \item 门槛前 4 小时停止新增范围，只修阻塞缺陷；
  \item 门槛会议必须产生“通过/有条件通过/不通过”记录及签字人；
  \item 重要口径不得只存在聊天记录，必须进入变更单或冻结文档。
\end{itemize}

\chapter{R2--G2：样本、字段和可得性冻结}

\section{R2 只做可得性，不做正式数据建设}
R2 的目标是证明每个字段在哪里、以什么频率、什么许可、什么缺失模式获得。可以读取少量样例或接口元数据，但不得把预审快照当成正式数据集。GEM 同时包含月度、季度和年度序列\autocite{worldbankgem}，WEO 属于年度数据库\autocite{imfweo}，AREAER 与 Chinn--Ito 主要作为年度政策变量\autocite{imfareaer,chinnito2023}；任何来源都必须按真实频率登记，不得复制成年内十二条“月度观测”。国别 GPR 只有在来源确有对应经济体月度序列时使用，不能默认覆盖全部 40 国\autocite{bdegpr2025}。

\section{三层样本与事件衍生层}
130 国是覆盖和投资版图母体，40 国是按规则筛选的量化层，20 家中国企业是公开披露画像层，危机事件从 40 国数据与权威资料中衍生。第一册附录中的 40 国只是候选池，不是冻结名单；最多六家深度企业也不预先指定。

40 国必须满足项目定义的亚非拉实体经营国、有中国投资或企业存在证据、2010--2025 年汇率和 CPI 月度完整率分别达到 80\%。香港、澳门、开曼、英属维尔京、百慕大等资金通道不参与实体经营风险排名。区域配额固定为亚洲及中东 15、非洲 14、拉丁美洲 11；每区先按规则保留 3 个低风险对照国，其余按“中国投资暴露百分位乘以预审风险百分位”排序，并列时依次按数据完整度、投资暴露、ISO 代码确定。

20 家企业名单与第一册一致：ICT 与电子为华为、中兴通讯、传音控股、联想集团；家电与消费制造为海尔智家、美的集团、海信家电、TCL 科技；汽车与新能源为比亚迪、上汽集团、吉利汽车、长城汽车；工程机械与装备为三一重工、徐工机械；基建与轨道交通为中国中车、中国交建；资源与能源为紫金矿业、洛阳钼业、中国海油、中国石油。MTN Nigeria、雀巢尼日利亚和 AB InBev 只作外部验证，不计入 20 家中国企业。

\section{字段可得性登记}

\section{危机识别与统计合同}
候选事件由以下任一条件触发：12 个月本币对美元贬值不低于 20\%；CPI 同比不低于 15\%；官方汇率与可信平行市场汇率差不低于 20\%；资本管制明显收紧；出现资金冻结、汇出限制或银行中断。同国同类触发连续出现或间隔不超过 2 个月时合并；所有定量指标连续 3 个月退出阈值，或正式限制解除后，事件才结束。窗口固定为开始前 12 个月至结束后 24 个月，事件性质须由一项 A 级或两项独立 B 级证据确认。

跨国模型使用国家固定效应与日历时间固定效应，按国家聚类稳健误差，并报告小簇稳健敏感性；三大区域分别估计或使用交互项。等权风险指数是透明主模型，熵权与 PCA 是挑战模型。所有结果只描述历史相关性和情景结果，不宣称因果关系。

\section{收益拆分单元测试}
任何本币黄金收益必须满足：
\[
1+r_{\text{本币黄金}}=(1+r_{\text{美元黄金}})(1+r_{\text{美元兑本币}}).
\]
单元测试至少包含：美元金价不变但本币贬值；汇率不变但美元金价变化；两者同时变化；缺失汇率；官方与平行汇率并存。结果页同时展示美元金价贡献、汇率贡献和交互项。

\section{G3 否决清单}
出现任一情况，G3 不通过：

\begin{itemize}
  \item 没有美元资产基准或把美元基准设置成不合理高成本；
  \item 含黄金结果没有与表现最好的非黄金基准比较；
  \item 默认黄金必为正权重，或报告模板无法显示 0\%；
  \item 用危机结束后数据决定危机开始时的策略；
  \item 成本、折价、可用性或合规约束没有进入模型；
  \item 官方和平行汇率混合却不标记；
  \item 模拟企业数据未标\Field{is_simulated=1}；
  \item 风险排名在等权、熵权和 PCA 下不稳定，却仍输出确定性建议。
\end{itemize}

恢复测试由未参与看板搭建的成员执行：在干净环境导入 XML 或导出包，连接示例数据，检查五页、筛选、下钻、指标、AI 功能和账号权限。记录环境、操作步骤、开始/完成时间、错误、修复和截图。只有“从零恢复成功”才算可复现；开发环境能打开不算。

  \item 正式数据分析报告；

\chapter{质量保证与最终验收}

\section{四层验证}
\begin{enumerate}
  \item \textbf{结构验证：}文件、字段、主键、类型、范围；
  \item \textbf{数值验证：}抽样回源、换算、公式、单元测试；
  \item \textbf{分析验证：}基准、公平窗口、成本、敏感性、负结果；
  \item \textbf{呈现验证：}图表可读、来源可见、交互、恢复、视频和 PDF。
\end{enumerate}

\section{Definition of Done}
一项任务只有同时满足“输出存在、格式正确、来源完整、验证人签字、遗留问题登记、下游可消费”才完成。代码运行成功、LaTeX 编译成功、Smartbi 页面能打开或文件已上传都不是单独的完成证明。

\section{跨册一致性}
两册和后续作品必须一致使用：项目名称；130 国覆盖、规则筛选的 40 国、20 家企业与事件衍生层；五个假设；六项指标；九张逻辑表；五页看板；20 个 AIChat 问题；R0--E3 阶段；A--D 角色和 8 月 31 日提交日期。任何改变先更新权威口径，再更新下游，禁止只改演示稿。

\section{最终终检问题}
\begin{enumerate}[label=\ensuremath{\square}]
  \item 忙碌评审能否在摘要和前两页知道项目有条件可行？
  \item 每个重要数字是否能回到文档页码而不是机构首页？
  \item 45 份案例是否全入矩阵且重复事件没有重复计数？
  \item 40 国、最多六家深度企业和危机事件是否都在 G2 后按规则冻结？
  \item 月度、年度和事件数据是否分表管理，九表接口是否一致？
  \item 每个含黄金结果是否与最佳非黄金基准比较？
  \item 结果是否允许黄金权重为 0\%？
  \item 2008 初期同跌、2013 暴跌、1980--2000 熊市等反例是否可见？
  \item 模拟数据是否全有\Field{is_simulated=1}和假设来源？
  \item 受限场景是否先停止建议并升级合规？
  \item Smartbi 是否在干净环境恢复，五页和指标是否一致？
  \item 20 个 AIChat 固定问题是否达到正确率、误差和停机要求？
  \item 视频是否不超过 3 分钟，8 月 31 日提交材料是否逐项可打开？
\end{enumerate}
