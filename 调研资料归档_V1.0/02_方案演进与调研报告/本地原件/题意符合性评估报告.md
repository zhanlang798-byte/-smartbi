# 题意符合性评估报告：跨国公司子公司黄金储备方案 vs XH-202612 赛题

> 评估对象：当前方案链路——服务对象为**跨国公司**（其高风险国别的**境外子公司**配置小额黄金作为"灾难保险型"应急流动性储备），基于已完成的金银数据底座 + 两份调研报告。
> 评估基准：XH-202612 赛题原文（评分：问题价值 20 + 数据分析方法与技术 25 + 可视化交互 25 + 创新性 20 + 完整可复现 10；另有平台/提交/合规硬性门槛）。
> 评估时间：2026-08。

---

## 一、题意符合性总判

**先回答核心问题：跨国公司 + 境外子公司的定位，与赛题有没有矛盾？——没有矛盾，符合题意。**

理由：
- 赛题要求"围绕**真实场景**，开展数据采集、清洗、建模、可视化及智能分析的全流程实践"，选题方向明确包含**企业运营**、区域经济等 6 类。"跨国公司的国别货币风险管理"是标准的企业运营/金融风险场景，痛点有财报级硬数据支撑（MTN、雀巢、IATA、俄退出损失），"有痛点、有数据、有价值"三条全部满足。
- 赛题考察的是**数据分析全流程能力 + Smartbi 平台应用**，而不是"服务对象必须是中国国内企业"。服务对象是谁，只影响故事怎么讲，不影响题意。
- 赛题明确允许"若无条件获取（真实数据），也可基于合理假设构建高质量模拟数据集，但需说明数据逻辑与来源依据"——我们"企业持金比例回测"的模拟部分有合规出口。

**真正决定分数的不是定位，而是执行缺口**（见下）。当前状态下评分预估如下。

### 1. 问题价值与现实意义（20 分）——当前 16–18

- **得分点**：痛点实证极强——MTN 两年汇兑损失约 11 亿美元、7 家头部公司合计 2.06 万亿奈拉、航司被困资金峰值 22.7 亿美元、俄退出损失超 1070 亿美元；权威来源充足（IMF、WGC、IATA、SEC 财报、Reuters），满足"引用至少 1 份权威资料 + 量化影响范围"的明确要求。
- **失分点**：①影响范围需要再做一层"与中国相关的量化"——评审更关心中国跨国企业（如传音非洲收入占比 50%+、华为 2025 净汇兑损失 12.68 亿元），建议把"中国出海企业受新兴市场货币风险敞口规模"算出来作为开篇数字；②伊朗/俄罗斯案例涉制裁敏感叙事，表述需中性化（定位为"货币风险管理研究"，不是"规避制裁教程"）。
- **修改建议**：补一组中国出海企业案例数据（传音、海尔、华为年报公开数据），把"量化影响范围"落到中国视角。

### 2. 数据分析方法与技术应用（25 分）——当前 13–16

- **得分点**：金银数据底座质量高（8 类来源、防前视对齐、lag1 特征、质量检查表、SHA-256 校验），直接对应评分关键词"ETL 流程、清洗规则"；数据可得性评估证明 80% 新增数据免费可得。
- **失分点（这是当前最大的一块缺口）**：
  ①**国别货币风险数据集还没建**——汇率（FRED/IMF）、通胀（WEO）、KAOPEN、制裁名单都只是"证明能拿到"，尚未采集整合；
  ②**分析模型还没建**——黄金储备回测（X% 储备转黄金 vs 纯本币/美元/NDF 基准）、国别风险评分模型都停留在草案；
  ③**AI 应用未落地**——评分关键词"RAG 知识增强、归因分析、AI 问数"目前全是规划；
  ④**性能优化证据缺失**——"数据时效 T+1→小时级、性能优化 ≥5%"需要实测数据支撑。
- **修改建议**：按"汇率+通胀+GPR+制裁事件→国别风险评分→黄金回测"顺序建数仓和模型；在 Smartbi 里配置指标语义层 + AIChat 问数；保留清洗规则文档（异常值剔除 ≤10% 等数字要写实）。

### 3. 可视化呈现与交互体验（25 分）——当前 3–5 ⚠️ 最大短板

- **现状**：只有 Excel 预览 PNG，没有任何 Smartbi Dashboard、没有交互演示、没有数据叙事设计。这一项与上一项合计 50 分，是当前方案"从构思到作品"的真正主战场。
- **修改建议**：围绕"用可视化讲清楚一个问题"设计一条叙事主线——
  **世界地图（国别风险评分）→ 单国下钻（汇率 vs 金价 vs 通胀走势联动）→ 案例公司（传音/MTN 汇兑损益归因）→ 黄金储备回测对比（持金 X% vs 基准）→ 结论与建议**。
  交互要求：下钻/上卷、动态筛选、响应 ≤10 秒。建议在 Smartbi 试用账号开通后优先做这一块的 DEMO。

### 4. 创新性与原创性（20 分）——当前 14–16

- **得分点**：选题本身有差异化——"企业灾难保险型黄金储备"在 BI 竞赛中几乎不会有撞题；有 C1–C9 传导链、防前视方法论、"精确源/代理/未公开"三分法数据治理等方法论创新；可叠加 NLP（财经新闻情绪因子，论文复现线已有词表）。
- **失分点/风险**：①创新叙事要收敛——同时讲"中小企业流动性 + 跨国公司避险 + 金价预测 + 论文复现"四条线会显得散，**建议主线只保留"跨国公司国别风险 + 黄金储备回测"**，其余降级为支撑材料；②需主动回应"为什么不用美元/NDF"（调研报告已备好论据）。
- **修改建议**：把创新点提炼为一句话："用 BI+AI 把央行级的储备多元化逻辑，降维成跨国企业子公司可执行的尾部风险保险方案"。

### 5. 完整性与可复现性（10 分）——当前 6–7

- **得分点**：数据文档体系是加分项（来源口径表、inspect.ndjson、校验和、README）。
- **失分点**：Smartbi 端还是空白——**"基于 Smartbi 导入 xml 资源可完整恢复"这一条目前完全不满足**，因为没有 Smartbi 资源可导出。
- **修改建议**：Smartbi 环境搭好后，第一时间建立"资源导出 xml + 恢复验证"流程，并把数据字典、合规声明模板补齐。

## 四、针对性修改清单（按提分效率排序）

1. **【门槛项，不做=0 分】开通 Smartbi 试用账号**，把现有金银 Excel 主表导入平台，跑通"数据接入→建模→出图"最小闭环。
2. **【+15~20 分】建可视化 DEMO**：按第五节的叙事主线做交互式 Dashboard（对应 25 分项）。
3. **【+8~12 分】补国别风险数据集**：FRED 汇率 + IMF WEO 通胀 + KAOPEN + OFAC 名单，与现有底座整合（对应 25 分项的 ETL 证据）。
4. **【+5~8 分】做黄金储备回测模型**：选定 2–3 个货币（NGN/ARS/TRY），回测 5%–10% 黄金储备 vs 基准的保值效果，产出量化结论（同时支撑"落地建议"）。
5. **【+3~5 分】配置 AIChat 问数与归因**：准备 3–5 个演示问题（如"雀巢尼日利亚 2023 年为什么亏损"），并验证 RAG 知识增强（接入调研报告做知识库）。
6. **【+2~3 分】补中国出海企业案例**（传音/华为/海尔汇兑损益），把影响范围落到中国视角。
7. **【叙事收束】** 主线只讲"跨国公司国别风险 + 灾难保险型黄金储备"，中小企业调研与论文复现线降级为附录素材；制裁相关表述中性化。

## 五、结论

- **题意符合性：符合，无矛盾。** "跨国公司 + 境外子公司"定位不但没有跑题，反而是差异化优势；需要收窄的只是方案叙事（灾难保险型小额储备，而非流动性储备主体）。
- **当前评分预估：52–62 分**——失分几乎全部集中在"Smartbi 平台零实操"导致的可视化（25）、AI 技术应用（25）、可复现性（10）三块，共 60 分里当前只拿到约 20 分。
- **执行到位后目标区间：80–88 分。** 路径清晰：门槛项（Smartbi 实操）→ 可视化 DEMO → 国别风险数据与回测模型 → AI 问数演示。
