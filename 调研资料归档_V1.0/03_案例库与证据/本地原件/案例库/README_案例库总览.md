# 案例库总览与论点地图

> 用途：XH-202612「Smartbi AI 驱动的数据创新平台研究」参赛作品——"黄金/白银作为灾难保险型储备资产"命题的历史证据库。
> 支撑文档：`命题可行性验证报告.md`（理论验证结论）、`跨国公司黄金硬通货需求调研报告.md`、`企业资产配置调研报告.md`。

## 一、案例库使命

为参赛方案的核心命题提供**海量、详细、可核验、最新**的历史证据：

> **黄金/白银在"灾难型尾部风险"（货币崩溃、恶性通胀、制裁冻结、地缘冲突）中是损失最小、最可靠的价值保全工具；其长期名义收益与货币增发挂钩（人民币计价 20 年复合约 9%）；在利率上行/经济复苏期表现最差。因此应定位为"灾难保险型小额储备（占流动性 5%–10%）"。**

每个案例档案用**同一危机的多资产对比数据**证明"金银损失最小"，并如实呈现反面边界。

## 六、检索数据标准

1. **来源优先序**：官方/权威机构（央行、IMF、WGC、交易所、监管机构、上市公司 SEC 财报）> 主流财经媒体（Reuters、Bloomberg）> 学术论文/书籍 > 其他，每份数据附 URL。
2. **最新优先**：优先收录 2019 年以后的事件（俄乌、中东、奈拉、比索、里亚尔、黎巴嫩），确保"最新"属性。
3. **多资产对比强制**：每个危机事件必须包含至少黄金/股票/本币三类资产的同期对比数据，直接支撑"损失最小"论点。
4. **反面如实**：每个维度至少 1 个反面/边界案例，如实在"佐证点与边界"节中说明。
5. **中国视角穿插**：企业篇含传音/华为/中国黄金等中国企业案例，支持"影响范围落到中国视角"。
