# XH-202612 调研资料包 V1.0

本包用于把既有调研、案例、数据和外部来源交给下一位团队成员或AI。它不是已完成的数据平台。

## 十分钟上手

1. 先读 `AI_CONTEXT.json`。
2. 用 `研究资料总清单.jsonl` 按 `asset_id`、状态和类别检索。
3. 先排除 `缺失受限与待办清单.csv` 中不可直接使用的资料。
4. 以V4.0为当前权威计划，旧版本只用于理解方案演进。
5. 通过 `local_path + sha256` 定位和核验原件。

## 关键边界

- 共登记 688 项资产，其中URL/DOI来源 507 项、无URL题录 1 项、案例 45 份。
- “完整”表示每个来源都有终态，不表示绕过版权或登录下载全文。
- `shared` 可进入AI交接包；`private_only` 仅进入本机冷备份；`metadata_only` 只有资料卡和来源信息。
- CSV/JSONL为权威清单；当前未生成XLSX镜像。
- 账号、密码、Cookie、会话令牌和Office锁文件均不封装。

## 复跑

复现脚本位于 `12_复现脚本与运行记录`。外部来源可能更新，重跑时必须使用新的run_id并保留旧快照。
