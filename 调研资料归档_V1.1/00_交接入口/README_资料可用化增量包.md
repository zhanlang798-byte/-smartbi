# 调研资料归档 V1.1：网页数据可用化增量包

本目录不替代、也不修改 V1.0。它把 V1.0 的688项来源拆分为“取得、内容、提取、正式用途”四种状态，并保存新增开放原件、HTML正文、HTML表格、失败原因和替代路线。

## 十分钟读取顺序

1. 读取 `00_交接入口/AI_CONTEXT_V1.1.json`；
2. 用 `source_action_registry_V1.1.jsonl` 按 `asset_id` 查找动作和用途；
3. 对本地159个HTML查看 `HTML本地文件逐项处理矩阵_159项_V1.1.csv`；全部196条HTML型来源查看另一张矩阵；
4. 需要正文或表格时进入 `02_提取正文`、`03_提取表格`；
5. 受限与失败项进入 `06_人工任务卡`，不得绕过登录或许可。

## 真实边界

- 688项均有唯一动作终态；这不表示688项全文均可合法下载。
- 自动提取结果是后续人工复核的候选，不替代页码、单位、统计口径和关键数字复核。
- V1.0始终是原始归档快照；V1.1只保存新增、替代和提取层。
