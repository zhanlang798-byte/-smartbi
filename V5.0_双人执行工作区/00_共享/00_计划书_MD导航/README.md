## 共同规则

- 状态只有 `PASS`、`FAIL`、`BLOCKED`。
- 没有截图、日志、文件、哈希或交叉复核，不能写 `PASS`。
- 每个对象只有一个写入者，另一人只能只读复核和提交问题单。
- G0、G1、G2必须按顺序通过；G2签收后模型才正式供B使用。
- G2后如修改字段、类型、关系或指标，A必须发布新修订号并说明影响范围。

```text
G0 输入锁定
  -> G1 数据P0
  -> G2 模型冻结及A/B签收
  -> G3 六页初验
  -> G4 AIChat 25问初验
  -> G5 XML恢复与材料齐套
  -> G6 双人交叉复核和最终放行
```

## 个人材料边界

双方可以在各自工作区保留个人草稿、提示词、学习笔记或临时模板。个人材料不应代替共享交接物、正式证据和最终交付物。
