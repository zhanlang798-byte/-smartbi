### 指标口径

| 字段 | 定义 |
|---|---|
| total_rows | 各原始主键组 n 之和 |
| key_groups | 原始主键组合的组数；包含空键组合 |
| duplicate_key_groups | n > 1 的组数 |
| duplicate_extra_rows | 各组 n - 1 之和 |
| null_key_rows | 任一主键字段 IS NULL 的行数 |
| blank_key_rows | 任一主键字段经 CHAR 转换、TRIM 后为空串的行数 |

TRIM 检查覆盖空字符串和数据库 TRIM 识别的首尾空格，不声称额外验证所有 Unicode 空白、业务编码合法性或来源真实性。重复检查按数据库当前比较/分组规则进行，未修改原始主键。
