## 1. 企业披露边界（DB03 / AI-06/07/08/09/10 的生命线）

- **真实状态**：company_overseas_exposure 共 **168 行 = 160 global + 8 region**；bridge_company_geography **8 条全是 region，国家桥 = 0**；total_revenue / overseas_revenue / overseas_revenue_share **可用值均为 0**。
- **能答**：20 家目录、行业、经营模式、财年范围、地区披露行数、已核验单项（如汇兑损益，带页码与 source_id）、通用情景。
- **不能答（硬失败）**：海外收入排名/占比 Top 名单；企业×国家重合结论；企业真实现金需求与真实持仓。
- **绝不**：把 8 条 region 拆成国家；生成企业国别风险分数。

## 2. 历史数据边界（DB06 / AI-22/23/25）

- **真实状态**：historical_crisis_event 18 条，start_date **全部 1970-01-01（异常占位）**，review_status **全部 pending（未审核）**，comparability_grade 为空；HIST001/002/018 的 modern_backtest_allowed = 0。
- **能答**：主题列表、可比性限制说明、为什么暂不能用于现代回测。
- **不能答（硬失败）**：任何 1929–2025 连续时间轴、具体历史因果/机制故事。
- **AI-25 特殊**：只许使用 HIST001 的两个指定字段：`modern_backtest_allowed=0` 与 `comparability_limit=历史压力层;记录金本位、银行体系和工具不可比性,不套用现代 ETF`；多用一字段即 FAIL。

## 3. 黄金定位边界（DB04 / AI-11/12/13/14/24）

- 黄金只是 **0%–20% 权重网格中的风险缓冲情景变量**；2.5%、5% 只是情景点。
- 必须**对称**展示：完整 / 去黄金 / 去美元三策略同键比较；正例与反例都摆。
- **绝不**：写成统一配置建议、只说支持黄金的窗口、预设唯一胜者。

## 4. 模拟与代理边界

- portfolio_scenario 是**模拟情景层**：不是企业实际值，必须带"模拟"标记。
- is_proxy = 1 的序列是**代理数据**：页面必须显示代理标记，不得冒充官方直接数据。

## 5. 缺失与截止期规则

- 缺失**保持为空**，任何页面、任何 AI 回答都不得填 0。
- 汇率 / CPI / 储备各有**独立数据截止期**，不得合并成统一"截至某日"。

## 6. 合规边界（AI-18/20）

- 政策 / 托管 / 兑换 / 制裁类问题：按 country_policy_year 状态回答；**待核（pending）→ 明确"转人工复核"**。
- **绝不**输出规避制裁、外汇管制、托管、兑换、利润汇出等限制的方法路径。

## 7. 事件与样本口径

- **23** 条正式 country_event ≠ **45** 条 case_evidence（证据条数），不可互相替代。
- **130 国**是目录覆盖；**40 国**是量化样本（7,680 行月度面板）。两处数字出现时必须说清是哪个口径。

## 8. 通用拒答模板（AI 固定话术骨架）

> 「现有数据不能可靠回答这个问题。**缺口**：______。**已确认的事实边界**：______。**合法补齐方式**：______。**下一步**：转人工复核 / 等待 ______ 数据。」

## 9. AI 固定回答顺序（写进 KB）

1. 先写当前筛选与口径；
2. 再写可验证事实 / 数值 / 或明确拒答；
3. 每个数字带：观测期（或财年）、单位、source_id、质量标记；
4. 再写反例、缺失、代理、模拟、政策、历史限制；
5. 最后给合法补证 / 人工复核 / 下一步——**不给绕行**。
