\section{MVP\_country\_latest.xlsx：40行}
\begin{statusbox}{字段合同}
主键iso3。字段包括国家/区域、latest\_fx\_value/date、latest\_cpi\_value/date、latest\_reserve\_usd/date、latest\_reserve\_import\_months/date、fx\_12m\_depr、cpi\_yoy、两个threshold\_multiple、max\_threshold\_multiple、trigger\_label、crisis\_event\_count、latest\_odi\_stock\_usd/year、source\_id、质量、missing\_reason、source\_run\_id、view\_run\_id、view\_version、generated\_at。

\end{statusbox}
\begin{itemize}
\item 主表只取dim\_country.is\_selected\_40=1，必须40行。
\item 每个指标独立取最新非空值及自己的日期。
\item fx\_12m\_depr=(本月本币/美元÷12月前本币/美元)-1；端点缺失则为空。
\item cpi\_yoy=(本月CPI÷12月前CPI)-1；端点缺失则为空。
\item 汇率阈值20\%、CPI阈值15\%；倍数分别除以0.20和0.15。
\item 两项达标=双触发；一项达标=单触发；两项都有值且均未达=未触发；无法判断=数据不足。
\item 事件数按唯一event\_id；投资取最新非空存量及其年份。
\item 随机5国手算误差≤1e-10。
\end{itemize}
