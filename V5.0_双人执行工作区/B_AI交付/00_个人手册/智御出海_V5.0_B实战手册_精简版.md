## 4. 每日固定动作（M00）

每天两次，各约 10 分钟，文件存 `00_共享\每日协调\`：

- **09:00 早会**：读 A/B 昨日日报 → 列今日任务（开始条件/停止条件/18:00 应交读数）→ 确认对象锁无冲突 → 写 `M00_MORNING_YYYYMMDD.txt` + `DAILY_OBJECT_LOCK_YYYYMMDD.xlsx`
- **18:00 晚会**：逐项拿证据核对（口头不算）→ 更新硬失败/模型变更/门槛状态 → 写 `M00_EVENING_YYYYMMDD.txt` + `DAILY_GATE_STATUS_YYYYMMDD.xlsx` + 次日第一任务清单
- **纪律**：状态只有 PASS / FAIL / BLOCKED，没有"完成 80%"；FAIL 不许删不许藏；门槛只按证据升级。
