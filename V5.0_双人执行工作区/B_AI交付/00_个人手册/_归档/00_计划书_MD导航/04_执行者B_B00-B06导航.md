# 执行者 B：B00-B06 导航

## 1. B 的职责边界

B 是以下对象的唯一写入者：

- 页面 DB03、DB05、DB06。
- AI 项目 AIP、知识库 KB、智能体 AGENT。
- 25 问测试和判分记录。
- 分析报告、175 秒视频、合规材料和最终提交包。

B 对 A 的 18+3 表、共享模型、指标、DB01/02/04 和 XML 恢复只有只读复核权。发现问题时提交问题单，不能修改 A 的模型或另建影子模型。

## 2. 固定执行顺序

```text
B00 接收并签收 A 的冻结模型
  -> B01 DB03 企业披露边界
  -> B02 DB05 决策和证据中心
  -> B03 DB06 周期和历史边界
  -> B04 AIP/KB/AGENT/AIChat
  -> B05 25问测试、修复和全量回归
  -> B06 报告、视频、合规和提交包
```

A 未通过 G2 时，B 可以继续做线框、知识规则、25问基准、报告框架和视频脚本；不能正式搭页，不能私建模型。

## 3. B00：接收并签收冻结模型

目标：证明 A 的模型接口确实可用、边界明确且 B 只能读取。

接收内容：模型和指标版本、18+3 对象及行数、主键/关系/字段/类型、DB03/05/06 可用字段和指标、已知缺口、变更日志、只读权限证明和签收记录。

B 必须亲自复核：

- [ ] 能查询但不能修改模型。
- [ ] 关键行数与 A 交接一致。
- [ ] DB03/05/06 所需字段可查询。
- [ ] 企业披露为 `168 = 160 global + 8 region`，国家桥为 0。
- [ ] 海外收入相关字段可用值为 0，不能进行收入排名。
- [ ] 18条历史记录均为 1970/pending，不能包装成真实历史。
- [ ] 已知缺口和禁止推断已经理解并记录。

只有全部通过项都有证据时，B 才在 G2 记录中签 `PASS`。

配套文件：[B00模型签收检查表](../03_B00模型签收检查表.md)。

## 7. B04：配置 AIP、KB、AGENT 和 AIChat

固定资源名：

| 资源 | 名称 |
|---|---|
| AI 项目 | `AIP_XH202612_V50_DECISION` |
| 知识库 | `KB_XH202612_V50_GOVERNANCE` |
| 智能体 | `AGENT_XH202612_V50_ASSISTANT` |
| 25问测试 | `QA_XH202612_V50_AICHAT_25` |

知识库只允许放入 7 类内容：

1. A 冻结模型交接和字段字典。
2. 指标公式、空值和日期口径。
3. 六页页面说明。
4. `source_id` 追溯规则。
5. 企业、历史、政策和模拟边界。
6. 25问、基准生成和判分规范。
7. 合规声明和正确拒答模板。

固定回答顺序：

1. 当前筛选和口径。
2. 可验证事实，或第一句明确拒答。
3. 每个数字附观测期/财年、单位、`source_id` 和质量。
4. 反例、缺失、代理、模拟、政策和历史限制。
5. 合法补证、人工复核或下一步，不提供绕行方法。

完成配置后先跑 5 道冒烟题，全部通过后再进入 B05。

## 8. B05：执行25问、判分、修复和全量回归

### 五类题型

| 题型 | 题号 | 通过标准 |
|---|---|---|
| 数值题 | 04/09/13/14/21 | 总体正确率至少90%，关键误差不超过1% |
| 集合题 | 01/03/05/11/12 | 完全一致，多1个或漏1个都FAIL |
| 来源题 | 17/19 | 要求的来源字段100%完整 |

纪律：在 AIChat 中提问，在 AIChat 外用 Excel 或原始工作簿独立判分；修复任意一题后必须重新执行全部25题。
