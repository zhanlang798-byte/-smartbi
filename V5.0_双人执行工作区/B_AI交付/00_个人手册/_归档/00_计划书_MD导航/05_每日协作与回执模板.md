## 3. 对象锁记录

```markdown
# DAILY_OBJECT_LOCK_YYYYMMDD

| 完整资源名 | 唯一写入者 | 只读复核人 | 开始时间 | 预计交付 | 当前状态 | 备注 |
|---|---|---|---|---|---|---|
|  | A/B | B/A |  |  | OPEN |  |
```

规则：同一对象只能有一个写入者；对方只能只读复核和提问题单。
