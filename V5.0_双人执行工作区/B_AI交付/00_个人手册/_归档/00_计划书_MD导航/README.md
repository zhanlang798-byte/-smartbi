## 三种状态

| 状态 | 含义 |
|---|---|
| `PASS` | 所有通过项都有可复核证据，允许进入下一阶段 |
| `FAIL` | 已执行但结果不符合标准，需要修复后重新测试 |
| `BLOCKED` | 因输入、权限、环境或依赖缺失无法继续 |

没有截图、日志、文件、哈希或交叉复核时，不能只凭口头说明写 `PASS`。

## 一眼看懂整个流程

```text
G0 输入锁定
  -> G1 数据 P0
  -> G2 模型冻结及 A/B 签收
  -> G3 六页初验
  -> G4 AIChat 25 问初验
  -> G5 XML 恢复与材料齐套
  -> G6 双人交叉复核和最终放行
```
