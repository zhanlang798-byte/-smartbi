## 8. 常用字段含义

| 字段/名词 | 本项目含义 |
|---|---|
| `iso3` | 三位国家代码，作为文本键 |
| `source_id` | 数字到来源登记的追溯键，不得编造 |
| `run_id` | 上游生成批次，不能混用不同批次 |
| `is_proxy` | 代理数据标记，页面和回答中必须显示 |
| `gold_weight` | 0%-20% 网格中的黄金情景权重，不是统一配置建议 |
| `review_status=pending` | 尚未人工核验，不能写成允许或已确认 |
| `modern_backtest_allowed=0` | 禁止把对应历史记录直接用于现代组合回测 |
| `PASS/FAIL/BLOCKED` | 唯一允许的任务和门槛状态 |
