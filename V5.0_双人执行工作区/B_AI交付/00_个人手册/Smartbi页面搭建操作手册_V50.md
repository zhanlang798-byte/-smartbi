## 3. 设计器通用操作（官方 V11 操作口径）

### 3.1 绑数据（官方"选择及处理数据"流程）

1. 空白页面点 **选择业务数据集** → 搜索关键字或按目录找到我们的模型 → **确定**。
2. 右侧**数据选择区**随即显示模型的 **维度 / 度量 / 命名集 / 参数**。
3. 字段多了不好找：点数据选择区的**搜索**，输入关键字过滤（搜表名/字段名都行）。
4. 官方实用功能——**维度和度量关联筛选**：勾选某度量后开启关联筛选，只显示和它有关联关系的维度（按模型表关联关系判断），防止选出无关联字段查出"全都一样"的废数。
5. ⚠️ **平台表名带 `V50_` 前缀**：参数清单写 `company_overseas_exposure.fiscal_year`，平台里找 `V50_company_overseas_exposure` 下的 `fiscal_year`。

### 3.2 加组件（官方三种方式）

左侧菜单栏 **组件** → 找到目标组件：**鼠标拖拽**到画布 / 在组件上**双击** / 点组件右上角 **"+"**。你当前账号左侧显示六类入口：**表格、图形、指标、筛选器、更多、AI**；DB05 只用表格、筛选器、更多。

### 3.3 绑字段（两种方式）

- **勾选**：选中画布上的组件后，在数据选择区**勾选字段**，系统自动分配到组件设置的对应区域；
- **拖拽**：把字段拖到右侧**组件设置**面板的对应区域（表格是"列区"，交叉表是"行区/列区/度量区"，指标卡是"指标"区）。

### 3.4 筛选器（作用范围最关键）

选中组件后，右侧筛选器区可能显示以下三组；不同版本折叠方式略有差异：

| 区域 | 作用 |
|---|---|
| **影响此组件的筛选器** | 只过滤当前组件——DB03 的 Global 卡只数 global 行就靠它 |
| **影响此页上多个组件的筛选器** | 页面筛选器对当前组件的影响；可查看或调整联动 |
| **此页上其他筛选器** | 页面上存在、但当前不影响此组件的筛选器 |

创建页面筛选器：左侧**添加组件 → 筛选器**，拖入单选/多选列表或下拉组件，再把字段拖到筛选器的数据区。选中筛选器后，在**组件设置 → 数据 → 筛选器设置**里改展示名、默认值、操作符。

筛选器的**作用范围**可选“相关数据集的所有组件”“同数据集的所有组件”“自定义”或清空已选组件。DB05 有两组不相连的数据域，必须选**自定义**并逐个勾组件，不能一律设成全页联动。

### 3.5 数据格式（官方入口——修"2,018"靠它）

入口：**组件设置 > 字段上的"更多"按钮 > 数据格式**。

- 自动（默认）：沿用数据集字段格式，仪表盘不处理；
- 自定义可设：**前缀 / 后缀 / 小数位数（0–9）/ 数据格式（千分位、科学计数法、"<否>"）/ 变换系列（万元、千元、百分比）**；
- 日期时间型可设日期/时间格式；
- 设错可点**清空**恢复字段原格式。
- 该设置为**组件私有**，优先级高于全局格式。

### 3.6 排版与保存

- 鼠标拖拉拽直接调整组件大小和排版；右下角有**画布缩放到最佳比例**；
- **文本组件**加标题（可动态引用筛选器值）；**属性**面板调标题/字体/背景/边框；**主题**面板换主题风格（保持默认浅色即可，装饰吃性能，10 秒红线）；
- 工具栏**保存** → **预览**；保存后的页面在"分析展现"对应目录，资源上**右键 → 分享**可对外分享。

## 4. 六类组件操作要点（含官方依据）

### 4.1 筛选器
顶部通栏、默认"全选/不限"；枚举值来自真实字段，不手填选项。页面级筛选拖入"影响此页面上多个组件的筛选器"。

### 4.2 汇总表（官方 pageId=114985794）
- 字段拖入**列区**（可多个维度/度量）；
- 排序：字段上设置排序，按 id 类字段升序（如 `company_id`）；
- 分页：默认每页 20 条、分页控件样式；属性里可改"鼠标滚动分页"或调每页条数/总行数/前往；
- 需要序号：组件设置 > 属性 > 基础 > **显示序号**；
- **空值显示为空白，严禁设成"显示为 0"**。

### 4.3 交叉表（官方 pageId=113545587）——披露矩阵用这种
- **行区**拖企业 `company_name_zh`，**列区**拖 `fiscal_year`，**度量区**放计数；
- 添加度量后系统自动把"度量名称"字段加入列区——多度量会并排显示（正好做"披露记录数/来源数"双值）；
- ⚠️ **默认最大列数 50**（属性里可调，最大 200）；财年 8 年×2 度量不会超；
- 把"度量名称"拖入筛选器区可动态切换显示的度量；
- `COUNT_DISTINCT(source_id)` 若组件不支持去重计数 → 按参数清单改用明细表展示 `source_id`，**不用普通计数冒充**。

### 4.4 指标卡（官方"指标看板"，2024-07 后 V11 更名"指标卡"，pageId=114985782）
- 只勾选一个度量、不勾维度 = 单指标卡效果；多指标时**第一个拖入的是主指标**（突出显示），其余为次要指标；
- 常用设置：组件设置 > 属性 > 基础 > **每行列数**、图标显示；系列设置 > **后缀**；
- **单卡过滤**：展开筛选器面板，把维度字段拖入**"影响此组件的筛选器"**并设默认值——DB03 粒度卡 A/B/C 分别设 `geography_level` = global / region / country；
- 值为 0 的边界卡必须展示并在副标题/提示里写明含义（"无国家级拆分"等），不得隐藏。

### 4.5 折线图（图形类-线图）
- 维度 `month_end` 拖 X 轴，度量拖 Y 轴；
- **空值必须断线**：不补 0、不插值、不前向填充（`equity_drawdown` 非空仅 113 条、`hy_oas_12m_change_bps` 仅 17 条，伪造连续序列踩红线 4）；
- 阈值线只能引用冻结规则集，不自造。

### 4.6 文本组件（左侧“更多 → 文本”）
- 标题、说明卡、七段简报用这种；双击文本区域进入编辑，可设置字体、字号、颜色、粗体、行距和对齐；
- 官方组件支持静态文本，也支持插入字段/函数。只有字段和筛选关系已冻结时才做动态文本；跨数据域、会变化但尚未能正确联动的数字不得伪装成动态值。

### 5.2 DB05 决策、约束与证据中心

> 2026-09-01 受控变更：DB05 政策表 C1 正式采用全量 2,744 行口径，默认页脚为 `共 2744 条 / 138 页`，不再采用 1,000 行截断；默认加载实测 0.685 秒。B 已签署 PASS，A 已完成只读复核 PASS；正式签收以共享回执为准。

DB05 的独立权威入口是 [`../03_页面线框/DB05_完整搭建操作手册_20260829.md`](../03_页面线框/DB05_完整搭建操作手册_20260829.md)。其中已经收录界面区域解释、每列的“维度/度量 → 表 → 字段”路径、字体布局、组件属性、异常恢复、联动矩阵和验收。本节只作快速摘要；**实际施工一律按独立手册 §5.1–§5.13，不能拿本节摘要代替逐按钮步骤**。

#### 5.2.1 先认清当前页面与不能做的事

1. 当前 Chrome 标签页标题应为 `DB05_XH202612_V50_EVIDENCE_CENTER`。先复用画布已有标题、4 个筛选器和标题为“政策与限制状态表｜待核不等于允许”的组件 1；只有对应对象确实不存在时才新增，避免重复组件。
2. 只使用当前冻结模型 `MDL_XH202612_V50_COUNTRY_RESERVE`。选择数据时，最近使用列表里还可能出现旧的 `P0_XH202612_V50_DATA`，**不要选旧模型**。
3. 本页核心组件固定为 4 个：政策表、来源追溯表、来源处置与复核表、七段简报。标题、4 个筛选器和页脚不计入核心组件。
4. 经现场需求确认，DB05 年份筛选范围只要求 2010–2025，2026 不纳入本页年份筛选验收；正式使用维度 `V50_dim_year.year_key`。来源登记表目前没有国家/年份关系，禁止把互不相连的筛选器设置成“所有组件”。
5. 只展示限制、来源和缺口；**不得写任何规避制裁、外汇管制、托管、兑换或利润汇出的方法路径**。空值保持空，不填 0。

#### 5.2.2 绑定正确的数据模型

1. 在页面右侧**数据**面板点蓝色按钮**选择业务数据集**。
2. 弹窗先看“最近使用”；找到并单击 `MDL_XH202612_V50_COUNTRY_RESERVE`，再点**确定**。如果没看到，切到全部目录后按完整名称搜索。
3. 绑定成功后，右侧应出现模型名和字段树。依次展开并检查：
   - `V50_country_policy_year`：应看到 `iso3`、`policy_code`、`value_label`、`manual_review_status` 等；数值区虽显示 **`year2`**、`value`，但 `year2` 已实测为固定 SUM 度量，不能做年份筛选或年份明细。
   - `V50_source_registry`：应看到 `source_id`、`data_class`、`formal_use_state` 等；数值区里实际显示 `revalidation_required`、**`is_proxy2`**。
   - `V50_dim_country`：应看到 `country_name_zh`、`iso3`。
   - `V50_dim_year`：维度区应看到 `year_key`，范围 2010–2025；不要选度量区的 `Σ year_key`。
4. **字段别名说明**：`year2` 是固定合计度量，多选下拉只得到 `5,530,428`，禁止使用。年份正式使用维度 `V50_dim_year.year_key`；2010–2025 即为已确认需求范围，2026 不要求进入下拉。`is_proxy2` 在 4 条来源登记中为空，组件 3 首版不使用，相关统计放入静态简报。
5. 任一表或上述字段缺失时停止搭建，截图记录“模型名 + 缺失字段”，交 A 侧处理；不要用相似字段替代。

#### 5.2.3 先定页面布局和统一视觉

当前设计器标尺约为 0–1200。以下尺寸按 **1180 px 内容宽度、左右各约 10–16 px 留白**设计；若你实际画布宽度不同，保持比例和 12 px 间距即可，不要为追坐标拉坏组件。

| 区域 | 建议位置/尺寸 | 内容 |
|---|---|---|
| 标题区 | 页面上方水平居中，W≈650–700，H≈64 | 主标题 + 一行“本页回答”介绍；参照现有 DB03 |
| 筛选器条 | 标题下方水平排列，总宽约 1,000–1,100，H≈52 | 4 个多选下拉；全部放好后再统一居中和等间距 |
| 第一行 | Y≈156，H≈268 | 左政策表、右来源追溯表，各约 578 宽 |
| 第二行 | Y≈436，H≈220 | 来源处置与复核表，通栏 |
| 第三行 | Y≈668，H≈260–300 | 七段简报，通栏；允许页面纵向滚动 |
| 页脚 | 简报下方，H≈28 | 截止日期、口径提示、状态 |

统一样式按下表设置。不要使用渐变、重阴影、花哨图标或深色主题。

| 项目 | 设置 |

#### 5.2.13 停止条件与最终验收
