## 2. 可选裁决方案及影响

### 方案 1：确认 DQ41 按“并行标签命中”验收，并把“主状态命中”另列为解释性检查

**做法**

- 由对象所有者书面确认 expected period tests 的目标是标签而非唯一主状态；
- 不改阈值、不填 0、不插值；按当前冻结数据/规则重跑六段标签测试；
- 同时保留主状态优先级检查，避免把“标签出现”等同于“主状态等于该标签”。

**影响**

| 后续项 | 影响 |
|---|---|
| 25 问基准 | 需要在基准元数据中写清 DQ41 的标签口径；不能直接宣称六段全部 PASS，必须以重测结果为准。1990、2000—2002 等 0 命中期未必因切换口径而通过。 |
| AI-15 | 直接影响解释文案：继续强制区分 `labels` 与 `primary_state`；若重测只改变判定口径、不改 660 行输出，现有数值可保留，但要做回归。 |
| AI-21 | 仍按最新月主状态与缺失原因回答；标签口径裁决不应把 2025-12 的“证据不足”改成某个确定状态，除非重跑结果证明输出改变。 |
| AI-24 | 当前使用 scenario 内嵌五分类分组；如不改数据/规则输出，数值基准原则上不变，但须回归确认分组与口径说明没有混用。 |
| G2 | 正式裁决和重测证据归档后可消除本单的口径不确定性；不自动消除 A03/A04 的其他 G2 阻塞。 |
| DB06 | 页面同时展示主状态与并行标签，并显示 DQ41 口径说明；不得把“标签命中”画成唯一主状态。 |

**风险**：当前证据显示有些时期因输入缺失或条件未触发而 0 命中，仅改验收口径可能仍不能让六段全过。

### 方案 2：补充 A 级银行事件 / 官方衰退等可追溯输入后，发布新运行版本

- 只接受有许可、可得时间和版本记录的数据源；历史日期异常也须先处理；
- 发布新数据/规则运行版，不覆盖旧冻结证据；
- 全量重跑 660 月状态、六段 DQ41、无未来信息审计和下游回归。

**影响**

| 后续项 | 影响 |
|---|---|
| 25 问基准 | 必须重算周期相关基准并记录新版本；不能沿用旧数值而只更新文字。 |
| AI-15 | 主状态分布、触发月数和解释可能改变，必须重算并复核标签/主状态。 |
| AI-21 | 最新月主状态、最近有状态月和 missing_reason 可能改变，必须重新定稿；在新证据前仍答“证据不足”。 |
| AI-24 | 若周期分组或 scenario 关联口径改变，五组样本数和策略差值须全量重算；不得只抽样替换。 |
| G2 | 属于数据/规则版本变更，需要新版本、变更记录和回归证据；完成前不宜把问题单记 PASS。 |

**风险**：目前没有可用数据源证据，时间、许可和无未来信息风险最高；为赶门槛临时回填属于禁止行为。

### 方案 3：确认冻结数据/规则是当前真值，修订 DQ41 预期并保留限制说明

**做法**
