## 二、DB03 中国企业海外风险与披露边界

### 1. 建议对象名

- 数据集：`DB03_XH202612_V50_COMPANY_BOUNDARY`
- 页面：`DB03_中国企业海外风险与披露边界`
- 默认状态：全企业、全财年；缺失值保持空，不转成 0。

### 2. 页面筛选器

| 顺序 | 展示名 | 字段 | 备注 |
|---|---|---|---|
| 1 | 企业 | `dim_company.company_name_zh` | 单选/多选均可，默认全选 |
| 2 | 行业 | `dim_company.industry` | 与企业联动 |
| 3 | 财年 | `company_overseas_exposure.fiscal_year` | 当前源快照范围 2018—2025 |
| 4 | 数据质量 | `company_overseas_exposure.quality_flag` | 必须保留真实质量标签 |

### 3. 四个核心组件

#### 组件 1：企业目录表

- 维度：`company_name_zh`、`company_id`、`industry`、`operating_model`。
- 默认排序：`company_id` 升序。
- 禁止项：不做海外收入排名、风险高低排名或企业优劣评分。
- 基线：20 家企业，`company_id` 去重后仍为 20。

#### 组件 2：企业 × 财年披露可用性矩阵

- 行：`dim_company.company_name_zh`。
- 列：`company_overseas_exposure.fiscal_year`。
- 值 1：披露记录数 `COUNT(company_overseas_exposure.company_id)`。
- 值 2：来源数 `COUNT_DISTINCT(company_overseas_exposure.source_id)`；若当前组件不支持去重计数，改用明细表展示 `source_id`，不要用普通计数冒充。
- 提示字段：`geography_level`、`geography_name`、`geography_revenue`、`review_status`、`quality_flag`。
- 解释：矩阵表示“已收录披露记录/来源”，不表示企业真实海外收入规模。

#### 组件 3：披露粒度边界卡

- 指标卡 A：`geography_level = global` 的记录数。
- 指标卡 B：`geography_level = region` 的记录数。
- 指标卡 C：`geography_level = country` 的记录数，值为 0 时明确展示“无国家级拆分”，不得隐藏。
- 当前源快照基线：`160 global / 8 region / 0 country`。
- `bridge_company_geography` 当前只有 8 条 region 记录，`iso3` 非空数为 0；不得生成企业 × 国家重合、国家级敞口或地图着色。

#### 组件 4：能答 / 不能答边界卡

- 数据源：`MVP_company_data_status`。
- 选择企业后展示：`answer_scope`、`prohibited_inference`、`missing_reason`。
- 辅助字段：`disclosure_rows`、`disclosed_field_nonnull_count`、`region_rows`、`country_rows`、`unique_source_count`。
- 文案必须跟随当前企业筛选，不写成对全部企业统一成立的结论。

### 4. 当前数据基线与硬边界

| 检查项 | 当前源快照 |
|---|---:|
| `company_overseas_exposure` 总行数 | 168 |
| 企业数 | 20 |
| 财年范围 | 2018—2025 |
| global / region / country | 160 / 8 / 0 |
| `total_revenue` 非空数 | 0 |
| `overseas_revenue` 非空数 | 0 |
| `overseas_revenue_share` 非空数 | 0 |
| `geography_revenue` 非空数 | 8 |
| `bridge_company_geography.iso3` 非空数 | 0 |

因此 DB03 当前只能回答目录、行业、财年、披露粒度、已核验地区金额及证据边界；不能回答海外收入排名、企业 × 国家暴露、真实现金需求或真实持仓。

### 5. 冻结后验收

- [ ] 页面默认态企业数 = 20，披露行数 = 168。
- [ ] 粒度卡 = 160 / 8 / 0；筛选后数值随筛选变化。
- [ ] 三个收入类字段空值仍为空，未被补 0。
- [ ] 任意地区记录可追到 `source_id`、`review_status`、`quality_flag`。
- [ ] 页面不存在国家地图、国家级敞口、海外收入排名或企业优劣结论。
- [ ] 三次典型筛选操作各 ≤10 秒并留截图。

## 三、DB06 全球周期与历史边界

### 1. 建议对象名

- 数据集：`DB06_XH202612_V50_CYCLE_CONTEXT`
- 页面：`DB06_全球周期与历史边界`
- 默认月份：最新可用月份；若状态证据不足，状态卡必须显示“未确认/证据不足”，不能回填上一期状态。

### 2. 页面筛选器

| 顺序 | 展示名 | 字段 | 备注 |
|---|---|---|---|
| 1 | 月份 | `MVP_cycle_state.month_end` | 当前源快照 1971-01-31—2025-12-31 |
| 2 | 周期主状态 | `MVP_cycle_state.primary_state` | 空值也是有效边界，不能过滤掉 |
| 3 | 复合危机 | `MVP_cycle_state.compound_global_crisis` | 1 / 空 |
| 4 | 策略 | `portfolio_scenario.strategy_id` | 3 种策略 |
| 5 | 观察窗口 | `portfolio_scenario.horizon` | 90d / 1y / 5y / 10y |
| 6 | 历史审核状态 | `historical_crisis_event.review_status` | 当前均为 pending |

### 3. 四个核心组件

#### 组件 1：周期状态卡

- 主字段：`primary_state`、`labels`、`compound_global_crisis`。
- 边界字段：`missing_reason`、`ruleset_version`、`view_version`。
- 当前最新月 `2025-12-31` 的 `primary_state`、`labels`、`compound_global_crisis` 均为空；必须展示其 `missing_reason`，不得擅自判定状态。

#### 组件 2：周期触发指标折线图

- 时间轴：`global_cycle_month.month_end`。
- 首屏建议指标：`industrial_production_yoy`、`cpi_yoy`、`real_policy_rate`、`yield_spread_10y_3m`、`sahm_realtime_value`、`nfci_expanding_percentile`、`equity_drawdown`、`hy_oas_12m_change_bps`。
- 提示字段：`quality_flag`、`vintage_date`、`fetch_date`、`source_id`。
- 阈值线只能引用冻结规则集；本清单不新增阈值。
- 空值保持断线。当前非空数差异很大，尤其 `equity_drawdown=113`、`hy_oas_12m_change_bps=17`，不得插值伪造连续序列。

#### 组件 3：同口径策略对比

- 必须同时固定：`iso3`、`window_end`、`horizon`、`cycle_state_at_end`；比较时不得跨这些键聚合。
- 分组：`strategy_id`、`scenario_id`、`gold_weight`。
- 指标：`cum_return`、`max_drawdown`、`recovery_months`、`cvar_95`、`cost_total`。
- 三种策略：`3layer_grid`、`3layer_ablate_no_gold`、`3layer_ablate_no_usd`。
- 基线：207,720 行、40 个国家、190 个窗口结束月、4 个 horizon、9 个 scenario；`weight_sum` 全部为 1。
- 必须同时展示收益与风险/成本，保留反例，不只挑最优结果。

#### 组件 4：历史事件边界表

- 字段：`historical_event_id`、`event_title_zh`、`start_date`、`end_date`、`comparison_basis`、`comparability_grade`、`comparability_limit`、`modern_backtest_allowed`、`review_status`、`source_id_primary`、`source_id_secondary`。
- 当前基线：18 条；`start_date` 全部为 `1970-01-01`；`review_status` 全部为 `pending`。
- `HIST001`、`HIST002`、`HIST018` 的 `modern_backtest_allowed=0`；其余 15 条为 1。
- 页面必须显式提示：当前历史表不能被解释为真实的 1929—2025 连续时间轴。

### 4. 当前数据基线与硬边界

| 检查项 | 当前源快照 |
|---|---:|
| `global_cycle_month` 行数 | 660 |
| 月份范围 | 1971-01-31—2025-12-31 |
| `MVP_cycle_state` 行数 | 660 |
| `primary_state` 为空 | 160 |

| `historical_crisis_event` 行数 | 18 |

### 5. 冻结后验收

- [ ] 最新月状态为空时显示证据不足及 `missing_reason`。
