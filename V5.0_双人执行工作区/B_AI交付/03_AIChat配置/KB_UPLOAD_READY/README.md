## 平台实际格式

当前知识库页面的“导入”控件只接受 `.csv`。七个 `.md` 文件在 macOS 文件选择器中会显示为灰色，它们只作为可审计维护源，不直接上传。

平台直接导入文件：`KB_XH202612_V50_GOVERNANCE_知识导入_V50.csv`。

- 模板来源：SmartBI 页面“下载模板”所得 `知识配置模板.csv`
- 固定表头：`标题,知识,标签,字段召回,应用范围,类型,状态,版本,使用时机,描述`
- 数据行数：7
- 编码：UTF-8 with BOM
- SHA-256：`bb6fc8eb82610b3bbff27ee89fd6f72eebf6152017237dd8afd923cc6b1c9aff`

## 导入检查

1. 在目标知识库 `KB_XH202612_V50_GOVERNANCE` 点击“导入”。
2. 只选择 CSV，不选择 `.md`。
3. 导入后确认列表恰好新增 7 条知识，不多不少，无标题或正文错位。
4. 核对七条均为“文本/启用”，然后用“向量库检索”逐类执行检索验证。
5. 若导入失败或只出现部分条目，保留完整报错和截图，不重复导入，以免产生重复知识。
